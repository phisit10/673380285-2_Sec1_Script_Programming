| **4. การนำโค้ดกลับมาใช้ (Code Reuse)** | โมดูลอรรถประโยชน์ เช่น ฟังก์ชันเชื่อมต่อ Database หรือฟังก์ชันส่งอีเมล สามารถนำไปใช้ข้ามโปรเจกต์ได้โดยไม่ต้องเขียนใหม่ |

## หัวข้อที่ 2: Python Standard Library

ตัวอย่างการสำรวจและยกตัวอย่างการใช้งาน **3 โมดูลน่าสนใจ** จากคลังไลบรารีมาตรฐานของ Python:

### 1. โมดูล `datetime`

* **วัตถุประสงค์:** ใช้จัดการเกี่ยวกับวัน เวลา และการคำนวณช่วงเวลาต่างๆ
* **ตัวอย่างการนำไปใช้:** ดึงเวลาปัจจุบัน, คำนวณวันหมดอายุของสมาชิก หรือคำนวณระยะเวลาความแตกต่างระหว่างสองวันที่

```python
import datetime

now = datetime.datetime.now()
print("ปัจจุบันเวลา:", now.strftime("%Y-%m-%d %H:%M:%S"))
```

---

### 2. โมดูล `os`

* **วัตถุประสงค์:** ใช้ปฏิสัมพันธ์กับระบบปฏิบัติการ เช่น การจัดการโฟลเดอร์, เส้นทางไฟล์ (Path) และสภาพแวดล้อมระบบ
* **ตัวอย่างการนำไปใช้:** ตรวจสอบว่ามีไฟล์อยู่ในระบบหรือไม่, สร้างโฟลเดอร์ใหม่ หรือดึงรายชื่อไฟล์ทั้งหมดใน Directory

```python
import os

current_dir = os.getcwd()
print("Directory ปัจจุบัน:", current_dir)
```

---

### 3. โมดูล `json`

* **วัตถุประสงค์:** ใช้สำหรับแปลงข้อมูลโครงสร้างใน Python (Dictionary/List) ให้อยู่ในรูปแบบ JSON หรืออ่านข้อมูล JSON เข้ามาใช้งาน
* **ตัวอย่างการนำไปใช้:** ส่งข้อมูลผ่าน Web API หรือบันทึกไฟล์การตั้งค่า (Configuration Settings) ของแอปพลิเคชัน

```python
import json

data = {"name": "Alice", "role": "Student"}
json_str = json.dumps(data)
print("ข้อมูลรูปแบบ JSON String:", json_str)
```
