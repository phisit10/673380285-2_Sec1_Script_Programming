## 📌 สรุปภาพรวมประจำสัปดาห์ (Week Overview)
สัปดาห์ที่ 3 ครอบคลุมการควบคุมทิศทางการทำงานแบบวนซ้ำ (Loops) ในภาษา Python เพื่อทำงานอัตโนมัติซ้ำๆ ได้อย่างมีประสิทธิภาพ:
- **`for` Loops & `range()`:** การวนซ้ำตามจำนวนรอบที่แน่นอน และการกำหนดช่วงตัวเลขด้วย `range(start, stop, step)`
- **`while` Loops:** การวนซ้ำตามเงื่อนไขตรรกะจนกว่าเงื่อนไขจะเป็นเท็จ เหมาะกับงานที่ไม่ทราบจำนวนรอบล่วงหน้า (เช่น เกมทายตัวเลข)
- **Nested Loops:** การซ้อนลูปเพื่อจัดการข้อมูลแบบ 2 มิติ หรือการพิมพ์ลวดลายรูปทรงเรขาคณิต (Pattern Printing)
- **Interactive Programs:** การนำลูปไปประยุกต์ร่วมกับเงื่อนไขสร้างโปรแกรมโต้ตอบ เช่น สูตรคูณ, นับถอยหลัง และเกมทายใจ

## 📝 รายละเอียดการทดลองและกิจกรรม (Labs & Activities)

### 1. Lab 3.1: โปรแกรมสร้างสูตรคูณ (Multiplication Table Generator)
- ใช้ `for` loop ในการวนคำนวณแม่สูตรคูณที่ผู้ใช้ป้อน พร้อมแสดงผลลัพธ์ตั้งแต่คูณ 1 ถึง 12 อย่างเป็นระเบียบ

### 2. Lab 3.2: โปรแกรมการนับถอยหลัง & เกมทายตัวเลข (Countdown & Guessing Game)
- ใช้ `while` loop ในการจำลองการนับถอยหลัง (Countdown)
- สร้างเกมทายตัวเลขที่ให้ผู้ใช้เดาค่าจนกว่าจะถูกต้อง พร้อมบอกใบ้ว่าค่าที่เดานั้น "มากเกินไป" หรือ "น้อยเกินไป"

### 3. Activity 3.1 & 3.2: Pattern Printing with Nested Loops
- ประยุกต์ใช้ลูปซ้อนลูป (Outer Loop ควบคุมแถว, Inner Loop ควบคุมคอลัมน์) ในการพิมพ์ลวดลายรูปดาวหรือตัวเลข เช่น รูปสามเหลี่ยมมุมฉากและพีระมิด

### 4. Challenge Section
- แบบฝึกหัดท้าทายการประยุกต์ลูปขั้นสูง เพื่อฝึกการคิดเชิงตรรกะและการควบคุมดัชนีของการวนลูป
