## 📌 สรุปภาพรวมประจำสัปดาห์ (Week Overview)
สัปดาห์ที่ 4 เป็นการศึกษาโครงสร้างข้อมูลแบบลำดับ (Sequence Collections) ในภาษา Python โดยเน้นการเปรียบเทียบและการใช้งาน List และ Tuple:
- **List (ข้อมูลแบบปรับเปลี่ยนได้ - Mutable):** การเก็บข้อมูลแบบเรียงลำดับที่สามารถเพิ่ม, แก้ไข, ลบ และจัดเรียงข้อมูลภายหลังได้
- **Tuple (ข้อมูลแบบคงที่ - Immutable):** การเก็บข้อมูลลำดับที่ไม่สามารถเปลี่ยนแปลงค่าได้ เหมาะสำหรับข้อมูลที่ต้องการความปลอดภัย ป้องกันการแก้ไข เช่น พิกัด GPS หรือค่าสี RGB
- **List Operations:** การใช้เมธอดสำคัญ เช่น `.append()`, `.insert()`, `.remove()`, `.pop()`, และ `.sort()`
- **Tuple Packing & Unpacking:** การกระจายค่าจาก Tuple ไปยังตัวแปรย่อย
- **Data Structure Decision-making:** วิเคราะห์บริบทการใช้งานจริงว่าข้อมูลลักษณะใดควรเลือกใช้ List หรือ Tuple

## 📝 รายละเอียดการทดลองและกิจกรรม (Labs & Activities)

### 1. Lab 4.1: Student Management System (List Operations)
- สร้างระบบจัดการข้อมูลนักเรียน โดยจำลองการเพิ่มชื่อนักเรียนใหม่, การค้นหา, การลบรายชื่อ และการเรียงลำดับรายชื่อตามตัวอักษร

### 2. Lab 4.2: Geometric Calculations (Tuples & Immutability)
- ใช้ Tuple เก็บพิกัดจุดทางเรขาคณิต เช่น `(x, y)` เพื่อคำนวณระยะทางระหว่างจุด
- แสดงคุณสมบัติ Immutability ของ Tuple ที่ป้องกันไม่ให้เผลอแก้ไขค่าพิกัดโดยไม่ตั้งใจ

### 3. Activity 4.1: List vs. Tuple: Scenario Matching
- วิเคราะห์สถานการณ์จริง 6 สถานการณ์ พร้อมให้เหตุผลว่าควรเลือกใช้ List หรือ Tuple เช่น:
  - *อุณหภูมิประจำวัน / ตะกร้าสินค้า / คะแนนนักเรียน* -> เลือกใช้ **List** (ข้อมูลปรับเปลี่ยนได้)
  - *ค่าสี RGB / รายชื่อวัน จ.-อา. / พิกัดสถานที่* -> เลือกใช้ **Tuple** (ข้อมูลคงที่)

### 4. Activity 4.2: Interactive To-Do List
- พัฒนาระบบ To-Do List แบบโต้ตอบ ที่ผู้ใช้สามารถเพิ่มงานใหม่ ตรวจดูรายการงาน และลบงานที่ทำเสร็จแล้วออกจาก List
