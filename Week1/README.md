## 📌 สรุปภาพรวมประจำสัปดาห์ (Week Overview)
สัปดาห์ที่ 1 เป็นการเริ่มต้นทำความรู้จักกับการเขียนสคริปต์ภาษา Python การจัดเตรียมสภาพแวดล้อมในการพัฒนาโปรแกรม และพื้นฐานสำคัญของภาษา:
- **Environment Setup:** การติดตั้งและเตรียมสภาพแวดล้อมการทำงานด้วย Python และ Jupyter Notebook
- **Variables & Data Types:** การประกาศตัวแปรและการจัดการชนิดข้อมูลพื้นฐาน เช่น Integer (`int`), Float (`float`), String (`str`), และ Boolean (`bool`)
- **Operators & Formatting:** การคำนวณทางคณิตศาสตร์เบื้องต้น, การต่อสตริง (String Concatenation), และการแสดงผลด้วย f-strings
- **User Input & Type Conversion:** การรับข้อมูลจากผู้ใช้ผ่านฟังก์ชัน `input()` และการแปลงชนิดข้อมูล (Type Casting)
- **Discussion & Puzzlers:** การวิเคราะห์ชนิดข้อมูลและแนวคิดการนำ Python Scripting ไปประยุกต์ใช้งานจริงในชีวิตประจำวัน

## 📝 รายละเอียดการทดลองและกิจกรรม (Labs & Activities)

### 1. Lab 1.1: Environment Setup & First Script
- ทดสอบความพร้อมของสภาพแวดล้อม Python และเขียนสคริปต์พิมพ์ข้อความแรกบนหน้าจอ

### 2. Lab 1.2: Working with Variables and Basic Data Types
- ประกาศตัวแปรชนิดต่างๆ และพิมพ์ผลลัพธ์
- ดำเนินการทางคณิตศาสตร์ (+, -, *, /)
- การใช้ f-strings ในการจัดรูปแบบข้อความ
- รับอินพุตจากผู้ใช้ แปลงประเภทข้อมูล และคำนวณพื้นที่รูปเรขาคณิตพื้นฐาน

### 3. Activity 1.1: Uses of Scripting Discussion
- อภิปรายแนวทางการนำ Python ไปใช้งานจริง เช่น โปรแกรมคำนวณเฉพาะบุคคล, วิเคราะห์ข้อมูล (Data Analysis), งาน Automate และการสร้างเกมอย่างง่าย

### 4. Activity 1.2: Python Puzzlers
- วิเคราะห์ Snippet โค้ด ทำนายผลลัพธ์ ตรวจสอบชนิดข้อมูล (เช่น ผลบวกระหว่าง `int` กับ `float` จะได้ `float`, ค่าตรรกศาสตร์ `bool`)
